# 09 · Room TV

Any TV with a browser can show a Ring Game table or a tournament. TV pages are **read-only** and unauthenticated apart from a display token. They never show player balances or individual picks on Ring Game TV.

## 1. Pairing (6-digit code)

The staff phone creates the code and the TV claims it.

1. On the TV, open once `https://<app>/#/tv/cash` (Ring Game) or `#/tv/tournament` and bookmark it. The page shows a 6-digit input ("Enter the 6-digit code shown by the Inspector") and a read-only note.
2. On the staff phone:
   - Table sheet → "Launch Ring Game TV": `POST /tv/cash-pairings {tableId}`.
   - Tournament → "Launch Tournament TV": `POST /tv/tournament-pairings {tournamentId}`.
   - Response: `{pairingCode: "123456", expiresInMinutes}`. The phone shows the code as "123 456", the TV address with a Copy button, and "This code refreshes automatically after n minutes" (default **10**).
3. The TV submits `POST /api/tv/cash-pairings/claim {code}` (or `/api/tv/tournament-pairings/claim`). The response is `{displayToken, tableName}` or `{displayToken, tournamentName}`. The TV shows "Connected — loading" and navigates to `#/tv/cash/<displayToken>`.
4. The phone shows "<table> is now live on the television. Keep managing it from this phone."

- The display stays valid for **24 hours** (per the tour page). Each TV can follow a different table.
- **Direct-link fallback** ("Use a direct link instead"): `POST /tv/cash-sessions {tableId}` / `POST /tv/tournament-sessions {tournamentId}` → `{token, expiresAt}`. The phone shows a QR, a copyable link `#/tv/<kind>/<token>`, and "Open". "Creating a new link disables the previous one."

Errors:

- `tv.pairing_rate_limited` (too many attempts; rate-limit claims per IP and code, inferred)
- `tv.pairing_unavailable`
- `tv.pairing_expired` ("use the new code")
- `tv.pairing_code_invalid`
- `tv.table_not_found`
- `tv.cash_only` (Ring Game TV only for cash tables)
- `tv.table_closed` (open the table first)
- `tv.club_missing`
- `tv.club_mismatch`

Only owners, managers and inspectors can create pairings (inferred from the "Inspector phone" wording).

## 2. Ring Game TV

- Data: `GET /api/tv/cash/:displayToken`. HTTP **410** means expired: "This TV link has expired — ask the Inspector to launch a new one".
- Realtime: a socket with `auth: {displayToken}`, which receives `hand:started`, `hand:betting-closed`, `hand:flop-revealed`, `hand:settled`, `hand:cancelled`. The TV refetches after settle, and reconnects indefinitely (backoff 1–10 s).
- Payload (inferred shape): `{table{name, status, joinCode, clubName, roomName}, hand{handNumber, status, cards, winningMarkets[], players, bets, stakedCents, paidOutCents, winners}, markets[]` (popular) `, recent[]` (last flops) `}`.

Screen states:

| State | Condition | Shows |
|---|---|---|
| Off air | Table not open | "Off air" |
| Picks open | `betting_open` | Hand number, a countdown to the next flop in seconds (when the server supplies it), popular markets (most picked this hand, no names) |
| Picks locked | `betting_closed` | "The flop is coming" |
| Result | `settled` | The flop, winning markets (or "No winning market"), hand totals: players, picks, played, won, winners |
| Waiting | No live hand | "Waiting for next flop" |

Always visible:

- club · room · table name, "Live"
- **last 5 flops** ("Recent flops"; "No settled flops yet")
- a **QR to join this table** (`<app>/#/join/<joinCode>`, or "Join code unavailable")

Never shown: names, balances, individual picks. The settle reveal animates, with the leaderboard or markets refreshing about 1.1 s after the flop.

## 3. Tournament TV

- Data: `GET /api/tv/tournament/:displayToken` (410 means expired). Socket events as for cash, plus `tournament:registered`, `unregistered`, `rebuy`, `addon`, `started`, `cancelled`, `level:updated`, `player:busted`, `finished`, `chips:updated`.
- Payload: `{tournament{name, status, …}, currentHand, levels[], prizePoolCents, leaderboard[{name, chips, status, place, payout}]}`.
- Shows:
  - Live tournament / Final results.
  - Hand "n of total", level, min per pick, "No limit" max, next level or final level, "Ends after hand #n" / "Starts at hand #n".
  - Prize pool and **prize breakdown**.
  - Players left.
  - **Leaderboard with names and chips** (Playing / Finished status, "+n more" beyond the visible places, animated reordering).
  - "No players registered yet".
  - "Tournament finished".

## 4. Launch UI (staff phone)

- Table sheet → "Ring Game TV" and tournament row → "TV View".
- Sheet: creating the code, the code, the TV address + copy, the refresh note, the read-only note, and the direct-link fallback.
- Toasts: "Television connected", "TV link copied", "Television address copied".
